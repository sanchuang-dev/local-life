# Initialization and migration boundary

This repository was initialized as a new project following the maintainer's stack decision: React + Vite + Tailwind CSS + React Router (TypeScript enabled for long-term maintainability).

The business reduction/addition discussion is still ongoing; the initial source provides only a route-enabled foundation. Old product decisions stay at [V0.3 PRD](https://github.com/sanchuang-dev/base-prototype/blob/demo/local-life/docs/PRD-V0.3.md) as historical context. No business screens or APIs have been migrated.

When a new product decision is ratified, track changes in this repository's own product contract and work-item Issue; do not keep a second synchronized PRD elsewhere. The old base-prototype /local-life/ URL stays live unless a separate release/cutover task explicitly changes it.

Dev GitHub Pages is a public preview, not real community, government, mobile operator, health, payment, or commerce service.
