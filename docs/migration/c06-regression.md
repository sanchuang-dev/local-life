## 1. 演示入口与导航边界

- 底部仍是临时的 **首页 / 发现 / 我的** 三 Tab，仅用于验证壳层样式和切换，不是新版产品导航。
- `我的` 页底部新增 **原型演示导航**，集中列出 V0.3 已迁页面。该入口明确标注“非产品导航”，只服务浏览回归和产品减法讨论。
- 五个历史模块（首页 / 社区 / 健康 / 惠生活 / 我的）均可到达：首页与我的走底部 Tab，社区/健康/惠生活通过“我的 → 原型演示导航”和首页常用服务进入；没有把旧版五 Tab 写入底部导航。
- 共享子页面通过 `state={{ from }}` 记住来源：我的 → 积分/设备/广电、健康 → 我的设备会返回来源模块；直接访问时回退到各自父级。
- 消息详情之间的“其他消息”、兑换页的积分/商品入口、积分页的任务/兑换入口也保留来源；广电 → 社区广播使用真实链接并可返回广电。
- 未知路由统一落到 404，提供“返回首页”和“浏览服务导览”两个出口。

## 6. I02 全站交互盘点范围与方法

I02 以 I01 合并后的真实构建产物为准，不按路由表推断。盘点覆盖 **18 个基础页面 + 4 个活动实体 + 3 类缺失实体空态 + 404，共 26 个 URL 状态**；在每个状态枚举当前 DOM 中可见的 `a[href]`、`button`、`input`，再实际点击。

- 主视口 375 × 812，窄屏 320 × 812；页面滚动容器为 `#main-content`，底栏在滚动容器外。
- 链接：逐个点击并核对目标 hash，确认目标页存在且不是 404。

- 统计口径：控件数按“每个页面状态可见实例”累计，同一底栏在 26 个状态各计一次；不是去重后的组件数。
